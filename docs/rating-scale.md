# Investment rating scale

Use this scale on every `decisions/` page. **Never** plain "buy" / "sell".

| Rating | Meaning |
|--------|---------|
| **A** | Strong candidate |
| **B** | Watchlist candidate |
| **C** | Neutral / fairly valued |
| **D** | High risk |
| **E** | Avoid until conditions improve |
| **U** | Unknown / insufficient data |

## Required fields on every decision page

- **Rating** — one of A–E or U
- **Confidence** — Low / Medium / High
- **Reasoning** — bullets; each must cite supporting `[[claims/...]]` or `[[sources/...]]`
- **Main risks** — link `[[risks/...]]`
- **What would change the rating** — concrete evidence or events that move it up or down
- **Valid until** — date after which the assessment should be revisited (e.g., next earnings)
- **Investor profile fit** — long-term / short-term / dividend / speculative; and "not suitable for ..."

## Tone

Conservative. "Appears attractive on a 12-month horizon, conditional on Q2 earnings confirming margin recovery" beats "is a buy". You produce decision support; the user makes the call.
